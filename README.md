# Tic Tac Toe Game

## About the Project
Tic Tac Toe is a simple two-player game developed using HTML, CSS, and JavaScript. Players take turns marking X and O on a 3×3 game board. The first player to get three marks in a row, column, or diagonal wins the game.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Interactive 3×3 game board
- Two-player gameplay
- Automatic winner detection
- Displays the game result
- Simple and user-friendly interface

## Project Structure
- `index.html` – Structure of the game.
- `style.css` – Styling and layout.
- `app.js` – Game logic and functionality.

## How to Run
1. Download the project.
2. Extract the project folder.
3. Open `index.html` in a web browser.
4. Start playing!
